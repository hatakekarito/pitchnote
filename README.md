# ピッチノート（中央・三脚・横から撮影版）

ピッチ中央から横向きに撮った少年サッカーの試合動画を解析し、時系列の試合レポートを作るWebアプリです。
すべてのファイルを同じ階層に置く構成なので、スマホからでもGitHubにアップロードできます。

## ファイル一覧（すべて同じ階層）

| ファイル | 役割 |
|---|---|
| index.html | 画面 |
| style.css | デザイン（印刷用の設定を含む） |
| main.js | 画面の制御 |
| config.js | 調整用の設定値 |
| detector.js | 人とボールの検出（YOLO） |
| tracker.js | 選手の追跡（カメラの動きの補正つき） |
| motion.js | カメラのズーム・横振りの推定 |
| teams.js | ユニフォームの色でチーム分け |
| identity.js | 追跡を背番号の付いた選手にまとめる |
| labeling.js | 番号を付ける画面 |
| analysis.js | ボール保持・パス・シュートなどの判定 |
| report.js | 時系列レポートの作成 |
| store.js | 解析結果をこの端末に保存 |
| draw.js | 描画 |
| _headers | Cloudflare 用の設定 |
| yolov8n.onnx | AIモデル |
| export_model.py | モデルを自分で作り直す場合のみ使用（PCで実行） |

## 前の版から更新する場合

- 追加：identity.js、labeling.js、report.js、store.js
- 削除：commentary.js（音声実況はなくなりました）
- それ以外はすべて上書き（yolov8n.onnx はそのままで大丈夫です）

## 使い方

1. **動画を選ぶ**：解析する範囲とメモ（例：「11/3 練習試合 前半」）を入れる。前半・後半は分けて解析
2. **チームの色を登録**：選手が大きく映った場面で一時停止し、「チームA」を押してその選手をタップ。チームBも同じように。審判・ビブスの控え・GKなども「除外」に登録すると精度が上がる。チーム名もここで入力
3. **解析する**：画面を開いたままで待つ
4. **選手に番号を付ける**：写真を見て背番号を入力し、Enterで次へ
   - 同じ番号を入れた写真は自動で1人にまとまる
   - 「同じ子かもしれない組み合わせ」は、見失った直後に近くに現れた選手。「同じ子」を押すとまとめる
   - 読めない写真は「動画で見る」で確認するか、空欄のままでOK
   - 間違えてまとめた場合は「まとめを解除」
5. **レポートを見る**：「印刷・PDFで保存」「テキストでコピー」（LINEなどに貼れる）

解析結果と番号はこの端末のブラウザに自動保存されます。ステップ1の「保存した解析」から開き直せます。場面の確認や再生には、同じ動画ファイルを選び直してください。
※ ブラウザの履歴やサイトデータを消すと、保存した解析も消えます。プライベートブラウズでは保存されません。

## レポートの内容

- まとめ：保持率、パス、シュート、ボール奪取、押し込んだ時間帯、一番長くつながった攻撃
- 時間帯ごとのボール保持：試合を区切って保持率とシュート数を比較
- 試合の流れ：攻撃のまとまりごとに「7番→10番→9番とつなぐ（パス2本）。9番がシュート。」のように時刻順で記述。タップでその場面を再生
- 主な場面：シュートとボール奪取の一覧
- 選手ごとの記録：番号ごとのタッチ、パス（成功/試行）、シュート、奪取、ドリブル

## Cloudflare Pages の設定

| 項目 | 設定 |
|---|---|
| フレームワーク プリセット | なし |
| ビルドコマンド | 空欄 |
| ビルド出力ディレクトリ | 空欄（エラーになる場合は `/`） |

## うまくいかないとき（config.js で調整）

- ボールが見つからない → `tilesX: 3`
- 処理が遅い → `tilesX: 1`、`sampleFps: 5`
- 選手が除外されてしまう → `color.maxDist` を 50 程度に。同じチームの色を日なた・日かげで複数登録
- 番号付けの一覧が多すぎる → `labeling.minTime` を 5〜8 に上げる
- 「同じ子かも」の候補が多すぎる／少なすぎる → `labeling.maxGap`、`labeling.maxSpeed`
- 「試合の流れ」が細かすぎる → `report.minPhaseTouches` を 3 に

## できないこと

- 背番号の自動読み取り（写真を見て入力する方式です）
- 走行距離・速度の正確な数値、ゴールの判定

## 使用技術

- 検出：Ultralytics YOLOv8（AGPL-3.0。公開・配布の際はライセンス条件を確認してください）
- 推論：ONNX Runtime Web
- 追跡：ByteTrack / BoT-SORT の考え方（カメラ動き補正）を簡略化して実装
